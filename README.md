# GAIA, site

Site estático (português e inglês) da plataforma **GAIA, Geração de Derivados
e Análise Inteligente de Ativos Amazônicos** (UFAM, Manaus).

Este repositório contém **apenas o site**. O código-fonte da plataforma não é
público. A plataforma pode ser usada em <https://gaia-platform.online>
quando o servidor do laboratório estiver ligado.

Como citar: veja a seção "Como citar" do site.
